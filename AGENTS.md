# Working in this repo

**`todo.md` is the single source of truth.** Read it first and work from it — it contains everything an agent needs:
the autonomous **working mode**, the **prime directives** (local-only, strict Docker isolation, ≥32k context floor),
the **engineering standards & tribal knowledge** (§4A), and the **backlog** of what's left (§5) with full inline detail.

There is intentionally no separate instruction scaffold: don't look for guidance in scattered docs. If you discover a
non-obvious, hard-won pattern worth preserving, add it to **§4A of `todo.md`** (not here). `done.md` is the shipped
archive; `CHANGELOG.md` is user-facing release notes; `docs/` holds only current, maintained references.
